Agent 上网，现在抓瞎

Agent 已经能写代码、改文档、管项目--但你让它去网上看看，它就抓瞎了。通用工具每一个都差一口气。

JS 渲染页读不到

SPA、数据接口页抓回来一堆空壳 HTML，正文是 JS 填进去的，纯 HTTP 拿不到。

→ 内置 V8，真渲染 + js_extract 抠结构化数据
Cloudflare / 反爬拦截

服务器 IP 被 403，或卡在 "Just a moment..." 挑战页，流程直接断。

→ 自动绕过 Turnstile + stealth TLS 指纹切换
只读不会动

能抓页面但不能点击、填表、登录、翻页。遇到要交互的就废。

→ 持久会话，索引化 click/input，像人一样浏览
截图要 Chromium

给 Agent 当视觉输入要截图，但 Puppeteer/Playwright 要装整个 Chromium，服务器扛不住。

→ 内置 Blitz 渲染栈，纯 CPU，无 Chromium
搜不到

没有好用的搜索：官方 API 要审批要钱，免费的质量差，国内国外还不通。

→ 5 引擎并发聚合去重，能搜网页也能搜图
抓回来一堆标签

通用爬虫返回原始 HTML，Agent 根本没法读，还得自己清洗。

→ 直接返回 markdown，Agent 拿来就能用

Agent 用浏览器，只要五件事

现在的主流方案要么是为调试而生（Puppeteer），要么只读不会动（Firecrawl）。AginxBrowser 从第一行代码就想清楚：Agent 到底要什么。

HTTP API + MCP

为什么不依赖 Chromium

这不是「更轻」的炫耀，是架构选择。Chromium 为人设计，要处理 GPU 合成、音频、扩展、多进程沙箱--Agent 一个都用不到，每一个都是部署负担和故障面。

🔒 TLS 指纹伪装

stealth 模式模拟 Chrome145 / Firefox133 / Safari / Edge，可按请求切换，绕开反爬指纹检测。

🧩 CAPTCHA 自动解决

检测验证码类型，可选 2captcha 自动解决。搜索不再因为验证码卡死。

☁️ Cloudflare 自动绕过

检测 "Just a moment..." 挑战页，自动等待 cf_clearance，不打断 Agent 流程。

🛡️ DNS 重绑定防护

内置 SSRF 防护 + DNS 解析后 IP 校验，MCP over HTTP 默认只收可信 Host，公网安全。

接入你的 Agent

MCP 或 HTTP 任选。Claude Code / Claude Desktop / Cursor 配一行就能用。

1 MCP 一键接入（Claude Code）
# 本项目就是一个托管实例，直接连公网端点：
claude mcp add aginxbrowser \
  --transport http https://browser.aginx.net/mcp
2 HTTP API 直接调用
# 抓取页面 -> markdown
curl -sS -X POST https://browser.aginx.net/fetch \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'

# 搜索 -> 聚合去重
curl -sS -X POST https://browser.aginx.net/search \
  -H "Content-Type: application/json" \
  -d '{"q":"macbook 价格","max_results":5}'

# 看能力清单（不抓网，秒回）
curl -sS https://browser.aginx.net/doctor | jq .
3 自己部署
# 单二进制，零依赖，systemd 守护
cargo build --release --features stealth,screenshot
./target/release/aginxbrowser
