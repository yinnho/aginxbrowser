## 300015 是什么

- **平台业务拒绝**，不是传输层缺签。
- 深挖回执（`tmp-agent/xhs-300015-deep.json`）捕获：`publish_render` **HTTP 461**，body 大致：
  - `code`: **300015**
  - `msg`: **「浏览器运行环境异常，请关闭/卸载风险插件或重启试试」**
  - `success`: false
- UI：创建页短暂 formish → 「加载失败」→ 跳  
  `https://www.xiaohongshu.com/website-login/error?...&error_code=300015&rejectUrl=/api/edith/product/publish_render`  
  标题「安全限制」。
- **不是**未签名时的 **HTTP 406 / code=-1**（缺 `X-s`/`X-t` 会先死在签名层）。今天签过、门闩压住抢跑之后仍 300015 ⇒ 签名层已过，卡在**环境 / 风险分**。
